  `Editor\Data\PlaybackEngines\WebGLSupport` موجود (WebGLSupport: INSTALLED ✔).
- **إصلاح TagManager.asset**: كان `tags: []` فارغاً → يكسّر `Camera.main` و`FindWithTag("Player")`.
  أُضيفت الوسوم السبعة القياسية (Untagged, Respawn, Finish, EditorOnly, MainCamera, Player, GameController) → README #16.
- **ملفات جديدة**:

  - `Assets/_Game/Scripts/StreamingDebugUI.cs` — شاشة FPS + موقع اللاعب + Active/Loaded chunks (إثبات الـ streaming في المتصفح). README #18.
- **إعدادات التحقق**: activeInputHandler=2 (Input System فقط — ضروري لـ SimpleCar/Keyboard.current)،
  WebGL: ذاكرة 32→2048MB نمو تلقائي، ضغط 0 (معطّل — أبسط للرفع). المانيفست (9 تشانكات) مطابق في 3 مواضع.
- **README**: صفوف #14 (مانيفست 9), #15 (WebGL parser), #16 (tags), #17 (mini builder), #18 (debug UI).
- **UPLOAD_TO_UNITY_PLAY.md**: ملف تعليمات عربي للرفع اليدوي (ضغط محتوى مجلد البناء، تسجيل دخول المستخدم نفسه، WASD للقيادة، شرح شاشة التشخيص).

2. ضغط **محتوى** مجلد البناء إلى `WebGLMini.zip` (index.html في جذر الـ zip).

## دروس
- Hub installer غير موثوق على هذا الجهاز (checksum hangs) → استخدم مباشرة `...exe /S /D=<editor dir>` للـ Editor والوحدات.

- لا تقرأ `Buildstreamingworld,cs` كسكربت — اسم ملف بفاصلة → Unity يتجاهله (artifact قديم).
